
# Ether&SteamBoys: Legacy

Sistema de gestión para juego de cartas — Proyecto Final de Ciclo

Aplicación para la gestión de un juego de cartas desarrollada en Java.

El proyecto está compuesto por una aplicación Android y una aplicación de escritorio, conectadas mediante una API REST a una base de datos MySQL.

La aplicación de escritorio permite al administrador crear Personajes, Objetos y Enemigos en la base de datos, mientras que la aplicación Android permite a los jugadores registrarse y tener acceso a todos esos datos, funcionando como una companion App durante las partidas del juego de cartas.
